# 帝國 —— 富豪養成模擬器

一局十年、四十季。買事業、發債、質押借款、跟對手併購,跑完之後看你排到
**真實富豪榜**第幾名。

**這裡的錢全部是假的。** 這是一個教學用的簡化模型,不是預測工具,也不是投資建議。

```
node tools/serve.mjs          # 開發伺服器(預設 :8787)
node tools/test.mjs           # 跑 28 條測試
node tools/test.mjs 地圖       # 只跑名字含「地圖」的
```

---

## 這個專案是怎麼來的

它原本是一個資產追蹤 App(ORBIT)裡的一個分頁 ——
25,000 行單檔前端裡的 4,400 行。抽出來的時候只有三個真正的相依:

| | |
|---|---|
| 存檔 | 自己的 key `orbit.tycoon.v1`,從第一天起就不經過主 App 的存檔 |
| 後端 | 只有一條 `/api/rich` |
| 共用工具 | 數字格式、佈景色彩、`escH`、帶逾時的 `fetch`、國界資料 |

**牆本來就砌好了**,所以這是搬家不是重寫。那 20 條測試也一起搬過來,
除了兩條必須改寫的(見下面),其餘一個字都沒動。

## 架構

單檔前端,沒有編譯步驟、沒有模組系統、沒有 npm 相依(playwright 只在測試用)。

```
index.html    CSS + 所有遊戲邏輯(~9,600 行)
world3d.js    畫面層:沙盤貼圖、3D 建築、傾斜鏡頭、季間過場(只讀 TY,不碰規則)
worker.js     Cloudflare Worker:只有 /api/rich,其餘轉交靜態檔案
tools/
  serve.mjs   開發伺服器
  test.mjs    28 條測試
cities.json   44 座城市的真實範圍(Natural Earth 都市範圍,沒有的用省州邊界),約 40KB —— 用無頭 Chromium 把 index.html 真的開起來跑
```

### 四條鐵律

1. **只碰自己的那一格。** 除了 `orbit.tycoon.v1` 和佈景偏好,不往
   `localStorage` 寫任何東西。這是這個遊戲可以被放心塞進別人網站的原因,
   而且**有測試守著**。
2. **金額用自己的格式器 `tyM()`。** 不走主 App 的 `fmtM()` —— 那條路上有
   隱私模式的倍率與美元換算,遊戲裡的三十億被乘上 0.372 會變成一個
   看起來很像真的、但誰也解釋不了的數字。
3. **亂數是可重現的。** 種子式亂數(mulberry32),種子與狀態都存檔。
   同一顆種子 + 同一串操作 = 同一個結果,測試才驗得動。
4. **畫面層只讀。** `world3d.js` 可以讀 `TY`,但不寫任何欄位、不呼叫 `tyRnd()`
   (畫面拿走一個亂數,同一顆種子接下來的事件就全部錯位)。按「下一季」時
   狀態先變、畫面後到 —— 過場只是重播。有測試守著:按畫面上的「下一季」
   跟直接呼叫 `tyNext()`,同一顆種子跑出來的整份狀態必須一模一樣。

### 畫面層(world3d.js)

| | 做什麼 | 為什麼這樣做 |
|---|---|---|
| 戰略地圖貼圖 | 參考 CoN 的綠陸藍海:海、大陸棚、綠色陸地與森林顆粒、白色國界,**勢力顏色直接染在貼圖上**(有主的國家加同色粗邊) | 國界用 world-atlas 的 TopoJSON:手機 50m、桌機 10m,自己解碼(不多一個依賴);載不到退回 110m。貼圖是 canvas 直接當 Texture,勢力變了才重畫 |
| 3D 建築 | 每個據點一座小城,照類型蓋(房子、旅館、塔樓、玻璃大樓、油槽、金條…),新蓋的會從地上長出來 | globe.gl 的 UMD 版沒匯出 THREE,所以建構子是**從 globe.gl 已經建好的物件身上撿的**,每個都用 `.type` 驗明正身;驗不過就退回 CSS 積木 |
| 部隊棋子 | 戰車(併購小組)、法院(律師團)、講台與旗子(遊說團)、西裝人像(經理人);在海上行軍變成船;敵軍用對手的顏色 | 駐紮的部隊從東南開始試八個方向,站在第一個落在陸地上的那一邊 |
| 傾斜鏡頭 | 高度 0.9 以下開始壓低,最近時斜 20° | 第一版 56°,使用者說太斜。控制器永遠算「正上方」的邏輯位置,每一幀算完才傾斜;關掉 globe.gl 的「朝游標縮放」(跟傾斜打架,縮放會跳) |
| 近看局部地圖 | 高度 0.62 以下,針對畫面那一塊另外畫一張 2048 的 canvas,貼在一片貼著球面的曲面上;邊緣淡出 | 整球貼圖 8K 也只有每度 23 像素,貼近一定糊。曲面每格不超過 1 度 —— 範圍太大時弦會切進球面,變成一條橫跨地球的條紋 |
| 行軍路線 | 貼地的大圓虛線(暗色底線 + 流動的亮線),目的地一圈目標標記 | 用 globe.gl 的 paths 圖層,不是弧線 —— 參考那款遊戲的行軍線是畫在地面上的 |
| 遠看兵種圖示 | 高度 0.95 以上,3D 棋子收起來,改成方形圖示(綠 = 你、紅 = 敵人);撞在一起就左右交替錯開 | 遠看一台 3D 戰車只有幾個像素,讀不出是什麼 |
| 懸停 | 滑鼠移到國家 → 描出國界 + 國家小卡;移到城市 → 城市範圍圈 + 城市小卡 | 只在有滑鼠的裝置上啟用(`hover: hover`);觸控直接點就開面板 |
| 國家卡 | 國旗、經濟(景氣、長期成長、波動、連動)、政策(風險、稅率、在地夥伴)、勢力排行、部隊與來襲 | 經濟模型以地區為單位;沒有城市的國家歸到最近的經濟圈,畫面上直說是推算的 |
| 桌機側欄 | 寬度 ≥ 900 時,據點 / 國家 / 部隊 / 對手面板改成右側側欄,地圖留著 | 手機維持整張蓋上去 |
| 城市地標 | 44 座城市各一個(台北 101、東京鐵塔、艾菲爾鐵塔、大笨鐘、自由女神、哈里發塔、東方明珠、金沙、歌劇院、金門大橋…) | 只用方塊、稜柱、錐台、角錐拼,每個幾百個三角形,同一種只算一次幾何;遠看收起來 |
| 城市真實範圍 | 懸停描出城市的實際輪廓,選中的城市常駐描青色邊界 | `cities.json` 是從 Natural Earth 擷取的(擷取程式在開發時跑一次),不在執行時抓大檔 |
| 地區景氣色階 | 五級:大熱 / 偏熱 / 持平 / 偏冷 / 大冷,**跟全球平均比** | 跟開局比的話十年後每一區都漲,整張地圖都是紅的。沒有城市的國家歸到最近的經濟圈(容易算錯的國家明確指定,例如菲律賓 → 東南亞) |
| 季間過場 | 季別橫幅、資源列數字跳動、各據點浮出賺賠、對手擴張的弧線 | 不擋任何按鈕(整層 `pointer-events:none`);`prefers-reduced-motion` 時不跳數字 |

⚠ 縮放的踩坑紀錄:globe.gl 的 `onZoom` 是在傾斜鏡頭「算完」之前觸發的 —— 縮放一定要用事件帶來的高度,
不能用 `W3D.alt`(那是上一刻的)。用錯的話鏡頭停下來後建築一直是拉遠時的超大尺寸,偏移量也放大,部隊被推到海上。

⚠ 效能的踩坑紀錄(使用者回報「整體操作太卡」之後量過、改過的):
- 整球貼圖上限 4K(手機 2K),近看的清晰度交給局部地圖;整球與點擊判斷用 50m,10m 只給桌機近看
- 小於 1 像素的點不畫;大陸棚不用 `shadowBlur`(改成三層描邊);每國輪廓存成 `Path2D` —— 切換圖層從 ~200ms 降到 ~9ms
- 換圖層時地圖顏色延到下一幀重畫,點擊當下不卡
- 局部地圖鏡頭停下 350ms 才重畫;**畫布換尺寸時一定要先 dispose 貼圖**,不然新內容會塞進舊尺寸的格子(糊掉又錯位)
- 跨換日線的國家(俄羅斯)要整環攤平再平移,逐點平移會跟鄰國的填色互相抵消(整片陸地變成海)
- 像素比上限 1.5;地圖資料沒變就不重建 3D 物件與名牌(`tyGlobeData` 的簽章)
- 懸停判斷先用國家外框篩

⚠ 貼圖的踩坑紀錄:
- 有貼圖之後 three-globe 會把地球材質的 `color` 設成 null —— Color 建構子要從 `emissive` 撿,不然整個 3D 層不會啟用
- 森林顆粒不能在大圖上一顆一顆畫(九萬個圓會觸發 GPU 看門狗、WebGL context 直接掉),要畫在 512 的小圖塊上再用 pattern 鋪
- 8K 貼圖只給回報 `maxTextureSize ≥ 16384` 的顯卡,其餘 4K

測試環境的地球是替身,3D 層會**安靜地不啟用** —— 所以 3D 本身的樣子只能靠截圖驗
(用真的 globe.gl 開起來看,320 / 390 / 680 / 1180 四種寬度)。

### 資本部隊(第二階段)

參考 Conflict of Nations 的單位系統,但「兵」是錢養的專業團隊:

| 部隊 | 駐紮效果 | 防守力 |
|---|---|---|
| ⚔ 併購小組 | 每季削掉該地區最強對手 3 點勢力、壓低競爭;駐在對手大本營的地區 → 敵意收購 +10%(最多 +30%) | 0.7 |
| ⚖ 律師團 | 不管在哪,每季關注度 −1.5 | 1.0 |
| 🏛 遊說團 | 每季人脈 +1.2、關注 +0.3 | 0.4 |
| 👔 經理人 | 那個城市的事業現金流 +15%(最多兩位) | 0.2 |

- **最多 6 支**(`TY_UNIT_MAX`),每季付招募價 8% 的維持費
- **下一季到位**:自己的部隊不管多遠,一律下一季到位並開始生效(使用者要求);對手打過來的部隊維持原本的行軍時間(1~2 季),給你反應的時間
- **對手會出兵**:關係差(< −25)又比你大的對手,「對你出手」那一支從「當場競爭 +2.2」
  改成派一支會走路的併購小組 —— 出發當季就上快訊、地圖上看得到它走過來、
  部隊面板寫著防守率。抵達那一季擲一次:擋下 → 名氣 +2;被攻破 → 當地競爭上升、
  目標城市的事業被挖走 6% 資本。同一個對手同時只派一支。
- 所有隨機都走 `tyRnd()`,而且只在真的有攻擊要判定時才擲

### 打擊(經濟版的飛彈與空襲)

| 武器 | 效果 | 冷卻 |
|---|---|---|
| 🚀 做空飛彈 | 打對手的大本營:他的身家 −4~8%,你賺回兩成(上限:花費的 1.5 倍)。關注 +8、他對你 −30 | 4 季 |
| ✈ 輿論空襲 | 打一個城市所在的地區:那裡勢力最大的對手 −12 勢力、對你 −15。名氣 −2、關注 +4 | 3 季 |

打出去對手會記恨 —— 關係掉到 −25 以下、而且他比你大,他就會派兵打回來。

### 拉線與動畫

- 點地圖上的部隊 → 小卡勾選要派哪幾支 → 「🎯 拉線派遣」,或直接從部隊標籤**拖一條線**到城市
- 武器卡上的「🎯 地圖上選」也是同一套:線從你的大本營拉出去,停在可以打的城市上會變綠並說明打誰
- 出發動畫:律師團 / 遊說團 / 經理人搭飛機(起飛、巡航、降落);併購小組近的開車,遠的**開到港口、沿海上航線(約 60 個航點:麻六甲、蘇伊士、巴拿馬、好望角…)、靠港再上岸**
- 飛彈是一道拋物線加尾煙,落地爆炸;空襲是三架戰機編隊,到了一串爆炸
- 城市周圍的東西(你的小城、對手大本營、部隊、地標)各自分到**陸地上的空位**,不擠在同一點、不站在海上

### 沒有後端也玩得起來

`/api/rich` 是唯一的 API,而它抓不到的時候遊戲會**退回虛構對手,並且在畫面上
直說**(有測試守這條)。所以你可以先純靜態部署,想要真榜單再接 Worker。

> 榜單來源是 Forbes 的即時富豪榜 JSON 端點,**非官方**:Forbes 沒有公開 API
> 文件,那條網址隨時可能改或關掉。所以失敗一律回錯誤,不拿過期資料充數。

## 搬家時真正動到的東西

抽出來之後跑測試,20 條裡有 5 條失敗。**全部都是環境差異,沒有一條是遊戲壞了**:

| 症狀 | 真正的原因 |
|---|---|
| 20 條全部卡在 `waitForFunction` 逾時 | harness 在等 `window.loadPF` —— 那是資產 App 的存檔函式,這裡沒有。改等 `tyStart` |
| 指揮台塌成 138px 高,上下兩列疊在一起 | 主 App 把每一頁包在 `.pg > #pgBody` 裡,**全螢幕的高度完全靠那兩層撐**。第一版直接把 `.tycon` 塞進 `#page` |
| `GLOBE_OK` / `countries` / `iso` / `FX` / `getRes` is not defined | 相依沒帶齊。一個一個補,測試會告訴你下一個是誰 |
| 佈景切換鈕看不到 | 有一條 `body[data-route="tycoon"] #topnav{display:none}` —— 指揮台是全螢幕的,主 App 的導覽列在這一頁本來就讓開。改成獨立的浮動鈕 |

### 兩條必須改寫的測試

**「模擬器不可以碰到真實的持倉與交易紀錄」** → 改成**「只准寫自己的那一格存檔」**。

這個 repo 裡根本沒有真實資產可以被弄髒 —— 那條風險是**結構上消失**的,
不是被測出來的。但規矩本身要留著,所以改成測同一件事的另一面:
玩完一整局之後,`localStorage` 裡除了 `TY_KEY` 和佈景設定,不可以多出任何一個 key。

**「切分頁不會一直生出新的 WebGL context」** → 原本測的是「切到 `#/holdings`
之後地球要回停車位」。這個遊戲只有一頁,沒有別的分頁可以切。

查了 `bindTycoon` 才發現原本那條**測錯了對象**:

```js
if(TY){ tyGlobeMount(); … } else tyParkGlobe();
```

地球回不回停車位,是「**這一局還在不在**」決定的,不是哪一個分頁、
也不是有沒有開面板(面板打開時地圖只是被 CSS 收起來,地球還掛在槽裡)。
所以改成測:放棄這一局、回到選劇本的畫面之後,地球要被收回去。

> 為什麼要在意:`renderPage()` 每次都 `innerHTML` 清空 `#page`。地球如果直接
> 畫在分頁裡,每重畫一次就是一個新的 WebGL context —— 瀏覽器同時只給十幾個,
> 切個幾次整顆地球就再也畫不出來,**而且不會報錯,只是變成空白**。

## 部署

Cloudflare Workers,從 Git 自動部署。`wrangler.toml` 是**唯一事實來源** ——
每次 `git push` 觸發部署,Cloudflare 會用那個檔案重建整份設定,
Dashboard 上手動加的東西會被清掉。要改設定就改那個檔案。

沒有 KV、沒有密鑰、沒有任何使用者資料。
