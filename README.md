# 帝國 —— 富豪養成模擬器

一局十年、四十季。買事業、發債、質押借款、跟對手併購,跑完之後看你排到
**真實富豪榜**第幾名。

**這裡的錢全部是假的。** 這是一個教學用的簡化模型,不是預測工具,也不是投資建議。

```
node tools/serve.mjs          # 開發伺服器(預設 :8787)
node tools/test.mjs           # 跑 29 條測試
node tools/test.mjs 地圖       # 只跑名字含「地圖」的
```

---

## 這個專案是怎麼來的

它原本是一個資產追蹤 App(ORBIT)裡的一個分頁 ——
25,000 行單檔前端裡的 4,400 行。抽出來的時候只有三個真正的相依:

| | |
|---|---|
| 存檔 | 自己的 key `orbit.tycoon.v1`,從第一天起就不經過主 App 的存檔 |
| 後端 | 只有一條 `/api/rich` |
| 共用工具 | 數字格式、佈景色彩、`escH`、帶逾時的 `fetch`、國界資料 |

**牆本來就砌好了**,所以這是搬家不是重寫。那 20 條測試也一起搬過來,
除了兩條必須改寫的(見下面),其餘一個字都沒動。

## 架構

單檔前端,沒有編譯步驟、沒有模組系統、沒有 npm 相依(playwright 只在測試用)。

```
index.html    CSS + 所有遊戲邏輯(~9,600 行)
world3d.js    畫面層:沙盤貼圖、3D 建築、傾斜鏡頭、季間過場(只讀 TY,不碰規則)
worker.js     Cloudflare Worker:只有 /api/rich,其餘轉交靜態檔案
tools/
  serve.mjs   開發伺服器
  test.mjs    29 條測試
cities.json   44 座城市的真實範圍(Natural Earth 都市範圍,沒有的用省州邊界),約 40KB —— 用無頭 Chromium 把 index.html 真的開起來跑
```

### 四條鐵律

1. **只碰自己的那一格。** 除了 `orbit.tycoon.v1` 和佈景偏好,不往
   `localStorage` 寫任何東西。這是這個遊戲可以被放心塞進別人網站的原因,
   而且**有測試守著**。
2. **金額用自己的格式器 `tyM()`。** 不走主 App 的 `fmtM()` —— 那條路上有
   隱私模式的倍率與美元換算,遊戲裡的三十億被乘上 0.372 會變成一個
   看起來很像真的、但誰也解釋不了的數字。
3. **亂數是可重現的。** 種子式亂數(mulberry32),種子與狀態都存檔。
   同一顆種子 + 同一串操作 = 同一個結果,測試才驗得動。
4. **畫面層只讀。** `world3d.js` 可以讀 `TY`,但不寫任何欄位、不呼叫 `tyRnd()`
   (畫面拿走一個亂數,同一顆種子接下來的事件就全部錯位)。按「下一季」時
   狀態先變、畫面後到 —— 過場只是重播。有測試守著:按畫面上的「下一季」
   跟直接呼叫 `tyNext()`,同一顆種子跑出來的整份狀態必須一模一樣。

### 畫面層(world3d.js)

| | 做什麼 | 為什麼這樣做 |
|---|---|---|
| 戰略地圖貼圖 | 參考 CoN 的綠陸藍海:海、大陸棚、綠色陸地與森林顆粒、白色國界,**勢力顏色直接染在貼圖上**(有主的國家加同色粗邊) | 國界用 world-atlas 的 TopoJSON:手機 50m、桌機 10m,自己解碼(不多一個依賴);載不到退回 110m。貼圖是 canvas 直接當 Texture,勢力變了才重畫 |
| 3D 建築 | 每個據點一座小城,照類型蓋(房子、旅館、塔樓、玻璃大樓、油槽、金條…),新蓋的會從地上長出來 | globe.gl 的 UMD 版沒匯出 THREE,所以建構子是**從 globe.gl 已經建好的物件身上撿的**,每個都用 `.type` 驗明正身;驗不過就退回 CSS 積木 |
| 部隊棋子 | 戰車(併購小組)、法院(律師團)、講台與旗子(遊說團)、西裝人像(經理人);在海上行軍變成船;敵軍用對手的顏色 | 駐紮的部隊從東南開始試八個方向,站在第一個落在陸地上的那一邊 |
| 傾斜鏡頭 | 高度 0.9 以下開始壓低,最近時斜 20° | 第一版 56°,使用者說太斜。控制器永遠算「正上方」的邏輯位置,每一幀算完才傾斜;關掉 globe.gl 的「朝游標縮放」(跟傾斜打架,縮放會跳) |
| 近看局部地圖 | 高度 0.62 以下,針對畫面那一塊另外畫一張 2048 的 canvas,貼在一片貼著球面的曲面上;邊緣淡出 | 整球貼圖 8K 也只有每度 23 像素,貼近一定糊。曲面每格不超過 1 度 —— 範圍太大時弦會切進球面,變成一條橫跨地球的條紋 |
| 行軍路線 | 貼地的大圓虛線(暗色底線 + 流動的亮線),目的地一圈目標標記 | 用 globe.gl 的 paths 圖層,不是弧線 —— 參考那款遊戲的行軍線是畫在地面上的 |
| 遠看兵種圖示 | 高度 0.95 以上,3D 棋子收起來,改成方形圖示(綠 = 你、紅 = 敵人);撞在一起就左右交替錯開 | 遠看一台 3D 戰車只有幾個像素,讀不出是什麼 |
| 懸停 | 滑鼠移到國家 → 描出國界 + 國家小卡;移到城市 → 城市範圍圈 + 城市小卡 | 只在有滑鼠的裝置上啟用(`hover: hover`);觸控直接點就開面板 |
| 國家卡 | 國旗、經濟(景氣、長期成長、波動、連動)、政策(風險、稅率、在地夥伴)、勢力排行、部隊與來襲 | 經濟模型以地區為單位;沒有城市的國家歸到最近的經濟圈,畫面上直說是推算的 |
| 桌機側欄 | 寬度 ≥ 900 時,據點 / 國家 / 部隊 / 對手面板改成右側側欄,地圖留著 | 手機維持整張蓋上去 |
| 城市地標 | 44 座城市各一個(台北 101、東京鐵塔、艾菲爾鐵塔、大笨鐘、自由女神、哈里發塔、東方明珠、金沙、歌劇院、金門大橋…) | 只用方塊、稜柱、錐台、角錐拼,每個幾百個三角形,同一種只算一次幾何;遠看收起來 |
| 城市真實範圍 | 懸停描出城市的實際輪廓,選中的城市常駐描青色邊界 | `cities.json` 是從 Natural Earth 擷取的(擷取程式在開發時跑一次),不在執行時抓大檔 |
| 地區景氣色階 | 五級:大熱 / 偏熱 / 持平 / 偏冷 / 大冷,**跟全球平均比** | 跟開局比的話十年後每一區都漲,整張地圖都是紅的。沒有城市的國家歸到最近的經濟圈(容易算錯的國家明確指定,例如菲律賓 → 東南亞) |
| 季間過場 | 季別橫幅、資源列數字跳動、各據點浮出賺賠、對手擴張的弧線 | 不擋任何按鈕(整層 `pointer-events:none`);`prefers-reduced-motion` 時不跳數字 |

⚠ 縮放的踩坑紀錄:globe.gl 的 `onZoom` 是在傾斜鏡頭「算完」之前觸發的 —— 縮放一定要用事件帶來的高度,
不能用 `W3D.alt`(那是上一刻的)。用錯的話鏡頭停下來後建築一直是拉遠時的超大尺寸,偏移量也放大,部隊被推到海上。

⚠ 效能的踩坑紀錄(使用者回報「整體操作太卡」之後量過、改過的):
- 整球貼圖上限 4K(手機 2K),近看的清晰度交給局部地圖;整球與點擊判斷用 50m,10m 只給桌機近看
- 小於 1 像素的點不畫;大陸棚不用 `shadowBlur`(改成三層描邊);每國輪廓存成 `Path2D` —— 切換圖層從 ~200ms 降到 ~9ms
- 換圖層時地圖顏色延到下一幀重畫,點擊當下不卡
- 局部地圖鏡頭停下 350ms 才重畫;**畫布換尺寸時一定要先 dispose 貼圖**,不然新內容會塞進舊尺寸的格子(糊掉又錯位)
- 跨換日線的國家(俄羅斯)要整環攤平再平移,逐點平移會跟鄰國的填色互相抵消(整片陸地變成海)
- 像素比上限 1.5;地圖資料沒變就不重建 3D 物件與名牌(`tyGlobeData` 的簽章)
- 懸停判斷先用國家外框篩

⚠ 貼圖的踩坑紀錄:
- 有貼圖之後 three-globe 會把地球材質的 `color` 設成 null —— Color 建構子要從 `emissive` 撿,不然整個 3D 層不會啟用
- 森林顆粒不能在大圖上一顆一顆畫(九萬個圓會觸發 GPU 看門狗、WebGL context 直接掉),要畫在 512 的小圖塊上再用 pattern 鋪
- 8K 貼圖只給回報 `maxTextureSize ≥ 16384` 的顯卡,其餘 4K

測試環境的地球是替身,3D 層會**安靜地不啟用** —— 所以 3D 本身的樣子只能靠截圖驗
(用真的 globe.gl 開起來看,320 / 390 / 680 / 1180 四種寬度)。

### 資本部隊(第二階段)

參考 Conflict of Nations 的單位系統,但「兵」是錢養的專業團隊:

| 部隊 | 駐紮效果 | 防守力 |
|---|---|---|
| ⚔ 併購小組 | 每季削掉該地區最強對手 3 點勢力、壓低競爭;駐在對手大本營的地區 → 敵意收購 +10%(最多 +30%) | 0.7 |
| ⚖ 律師團 | 不管在哪,每季關注度 −1.5 | 1.0 |
| 🏛 遊說團 | 每季人脈 +1.2、關注 +0.3 | 0.4 |
| 👔 經理人 | 那個城市的事業現金流 +15%(最多兩位) | 0.2 |

- **最多 6 支**(`TY_UNIT_MAX`),每季付招募價 8% 的維持費
- **下一季到位**:自己的部隊不管多遠,一律下一季到位並開始生效(使用者要求);對手打過來的部隊維持原本的行軍時間(1~2 季),給你反應的時間
- **對手會出兵**:關係差(< −25)又比你大的對手,「對你出手」那一支從「當場競爭 +2.2」
  改成派一支會走路的併購小組 —— 出發當季就上快訊、地圖上看得到它走過來、
  部隊面板寫著防守率。抵達那一季擲一次:擋下 → 名氣 +2;被攻破 → 當地競爭上升、
  目標城市的事業被挖走 6% 資本。同一個對手同時只派一支。
- 所有隨機都走 `tyRnd()`,而且只在真的有攻擊要判定時才擲

### 打擊(經濟版的飛彈與空襲)

| 武器 | 效果 | 冷卻 |
|---|---|---|
| 🚀 做空飛彈 | 打對手的大本營:他的身家 −4~8%,你賺回兩成(上限:花費的 1.5 倍)。關注 +8、他對你 −30 | 4 季 |
| ✈ 輿論空襲 | 打一個城市所在的地區:那裡勢力最大的對手 −12 勢力、對你 −15。名氣 −2、關注 +4 | 3 季 |

打出去對手會記恨 —— 關係掉到 −25 以下、而且他比你大,他就會派兵打回來。

### 事業等級、金庫、資料頁

使用者說資產 / 事業 / 手法「太多東西,不知道要幹嘛,也不知道有沒有用」。

- **事業等級 Lv1~10**:主按鈕只有一個「⬆ 升級」—— 花現在資本的一半、資本 ×1.5,
  按下去之前就寫著「花多少、每季多賺多少、幾季回本」。上市是里程碑(Lv5 那一格有金框)。
  其餘動作(自訂加碼、借殼、賣掉、拆賣、破產保護)收進「更多動作」。
  等級是從「資本 ÷ 開辦資本」**算出來的**,不另外存 —— 舊存檔、合資、買來的公司都自動有等級
- **🏦 金庫**(底部新分頁):槓桿儀表(綠 < 50% < 黃 < 80% < 紅)+ 質押維持率 + 每季利息,
  底下是借款 / 還款、證券質押、控股層與空殼、錢放在哪裡、信託。手法頁只留居住地、在地夥伴、影響力
- **📊 資料**(右側按鈕):身家組成、每一筆資產、每一家公司(含等級)、部隊與武器冷卻、在地夥伴、對手 —— 一頁看完
- 富豪榜移出底部列(頂列金色的淨值鈕就是富豪榜)

### 拉線與動畫

- 點地圖上的部隊 → 小卡勾選要派哪幾支 → 「🎯 拉線派遣」,或直接從部隊標籤**拖一條線**到城市
- 武器卡上的「🎯 地圖上選」也是同一套:線從你的大本營拉出去,停在可以打的城市上會變綠並說明打誰
- 出發動畫:律師團 / 遊說團 / 經理人搭飛機(起飛、巡航、降落);併購小組近的開車,遠的**開到港口、沿海上航線(約 60 個航點:麻六甲、蘇伊士、巴拿馬、好望角…)、靠港再上岸**
- 飛彈是一道拋物線加尾煙,落地爆炸;空襲是三架戰機編隊,飛越目標上空投彈
- 第二輪(使用者:「不要太快結束」「客機 / 軍艦」「要有震動、火花」):客機(圓機身、後掠翼、四具引擎、窗戶)、
  驅逐艦(艦橋、雷達、主砲、垂直發射器、直升機甲板)、三輛卡車的車隊;飛機 5~10 秒、船 8~16 秒、飛彈 4~7 秒;
  開演前鏡頭先飛過去;凝結尾 / 航跡;爆炸 = 震動 + 閃光 + 火球 + 火花 + 燒一陣子的火 + 煙 + 衝擊波。
  手機上按發射時先收起面板(面板打開時地球會暫停繪圖,動畫等於播給空氣看)
- ⚠ 開發機一幀要畫好幾秒,截圖拍到的常是舊畫面。驗證動畫用 `W3D._tfix`(把動畫凍結在某個進度)+
  `W3D._step()`(手動推一格)+ 手動 `renderer.render` 後立刻 `toDataURL` —— 那才是當下真正的畫面
- 城市周圍的東西(你的小城、對手大本營、部隊、地標)各自分到**陸地上的空位**,不擠在同一點、不站在海上
- 第三輪(使用者:「定位不夠精準」「陸軍跨海要先搭船」):
  - 旁邊的位子用**度**算,並且在**當下鏡頭高度的那個距離**檢查是不是陸地(16 個方向 × 5 種距離,
    依距離分桶快取)。第一版的偏移是「幾塊地磚寬」、陸地只在固定距離檢查,拉遠之後站的點早就不是檢查過的點
  - 陸路的部隊沿線取樣:直線經過海就走「開到海岸 → ⚓ 登船(停一下)→ 航線 → ⚓ 靠岸 → 上岸」。
    第一版只看距離,台北開卡車直接橫越台灣海峽。港口 = 城市往第一個航點走、第一個落在海上的點

### 對手看得到、勢力拆三層、建築同一把尺(第七輪)

- **對手駐軍**:勢力每 25 點一支(最多 3 支),站在他在那個經濟圈的據點,兵種跟著流派。
  它是勢力的**畫法**,不是新規則 —— 不擲骰、不進存檔;削他的勢力,駐軍就撤。點下去開他的卡
- **對手動態**:`tyRivalTurn` 把每個動作記進 `TY_RV_EV`(不進存檔、不擲骰),季末地圖上播:
  擴張 = 他的客機飛過去插旗、出兵 = 車隊 / 船真的開過來(鏡頭會轉過去)、併購 = 被吃的那家爆炸、
  上市 = 大本營冒光、斷頭 = 冒煙、放話 = 你的大本營跳一則。對手面板最上面是最近四季的動態與駐軍清單。
  紀錄帶 `rid`(誰做的)
- **勢力分三層**:經濟圈(規則裡真正的數字)→ 國家(× 在那國站得多穩:大本營 1.0、駐軍 0.8、有城市 0.5、其餘 0.3;
  你:有資產 0.6~1.0、沒有 0.3)→ 城市(真實邊界上色,直接比錢:你在那座城的規模 vs 對手大本營身家六成 vs 駐軍)。
  「📊 勢力分析」頁一層一層展開。換算在同一輪畫面裡快取(`TY_PWC`),`tySave` 與 `renderPage` 都會丟掉
- **建築高度同一把尺**(`tyHeightScale`):全圖最大的(你某座城或某個對手的身家)滿格,每小十倍矮三分之一,
  小一千倍貼地。你每座城最高那棟 = 你在那座城的總規模,所以可以直接跟對手大本營比。據點面板有「規模比較」
- **捲動不跳頂**:`renderPage` 整頁重畫前記下捲動位置(鑰匙 = 重畫前開著的面板 + 選中的城市 + 元素 class),
  重畫後還原;換面板自然回到頂端。「更多動作」的展開狀態同理

### 卡牌 + 像素風(第八輪)

使用者:「把現在有的東西改成卡牌類型」「更寬鬆」「全部變成像素風格,包含所有建築、軍事」
「建築卡拖出去可以選賭場飯店等等,就會多一棟對應的房子」「底部取代掉,另外要有總覽清單」。

- **行動點**:每季補滿,基本 6 點、人脈每 25 點 +1、最多 9 點。每張牌寫著要幾點
  (建設 2、投資 / 升級 / 部隊 / 談判 / 遊說… 1、飛彈與空襲 2、變現與金庫 0)。
  ⚠ 行動點只管**畫面上的操作**(`tyDo`):規則函式(`tyFound`、`tyBuy`…)本身不扣點,
  測試與重播直接呼叫它們 —— 扣點會讓同一個種子跑兩次結果不一樣。
  判斷「做成了沒」看 `tySave` 有沒有被呼叫(`TY_SAVES`),做成了才扣
- **手牌**取代底部功能列;資產、事業、金庫、部隊、對手、勢力分析、手法收進「☰ 總覽」
- **出牌**:把牌往上拖到地球的城市(或點一下牌、再點城市)→ 跳出那座城市能做的選項。
  建設牌列出那座城開得了的事業(賭場飯店、科技公司、銀行…),蓋下去地圖上就多一棟那種像素建築;

### 3D 像素、像素地圖、像素特效、出牌回饋(第九輪)

使用者:「地圖上的東西也要 3D 立體像素風格」「地圖也改成像素的,加一些山脈湖泊河流」
「爆炸特效也改成像素」「卡牌丟出去要有回饋感」「字和東西都卡在一起」「表情符號也要像素」。

- **體素**(`world3d.js` 的 `voxAdd`):把 pixel.js 的每一張圖擠出成方塊 —— 正反面每個像素一片,
  側面與頂面只在邊緣沿著厚度長一整條(三角形數量才壓得住)。描邊在側面改用往內一格的顏色、在屋頂改用
  這張圖的主色,不然整棟樓是黑的。一座城 = 前後兩排建築 + 一塊隊伍色的地基。
  ⚠ 模型往**北**仰 0.8 弧度:鏡頭幾乎從正上方看(使用者要的),不仰的話只看得到屋頂;
  第一版往南傾,正面反而轉去對著地面。⚠ 頂點顏色要先從 sRGB 轉線性
- **像素地圖**(`terrain.js`):內建示意用的主要山脈稜線、大湖、大河(手抄座標,半度精度)。
  海三段深淺 → 大陸棚 → 陸地逐像素決定地貌(緯度 + 沙漠區 + 經緯度雜湊的雜訊,不用亂數)→ 岩石帶 + 像素小山 →
  湖與河 → **量化到調色盤**(抗鋸齒的中間色全部吸掉)。整球 2048×1024、近看局部 640,都用最近鄰取樣
- **像素特效**(`PX.fx`):爆炸、衝擊波、閃光、火、煙、塵土、金幣、星星都是程式畫的序列幀,
  CSS `steps(N)` 一格一格播。截圖驗證要 `W3D._fxHold = true`(不然開發機截圖太慢,特效已經被清掉)
- **出牌回饋**:做成之後那張牌翻滾著飛到城市(`steps(14)`)→ 星星、閃光、衝擊圈、輕震;
  建設揚塵土、投資與變現噴金幣,浮出「+飯店與賭場」。遊說 / 媒體 / 慈善飛到資源列那一格並閃一下。
  行動點用掉的那幾格會燒紅、新的一季補滿時一格一格跳回來、手牌重新發一次;部隊一格一格上下彈
- **去擁擠**:同一座城的部隊(駐紮 + 下季到位)合併成一個標記(「×3 +2」);部隊標籤一律避讓
  (撞到別的標籤或城市名牌就依序往下、上、右、左挪)
- **表情符號 → 像素圖示**:`PX.ICON` 約 70 個 9×9 圖示;`PX.observe` 盯著整頁,任何新長出來的文字節點裡的
  表情符號換成 `<img class="pxi">`(title 屬性換不了、下拉選項裡直接拿掉)。國旗改成三條色帶的像素旗

### 立體地形、所有動作的回饋、武器冷卻(第十輪)

使用者:「地形也要立體,要跟地圖很完美的融合,從我的視角看下去要很自然」「所有卡牌和東西都要和炸彈一樣的回饋感」
「空襲和飛彈的效果很好,但冷卻太久了,又怕破壞平衡」。

- **高程**(`terrain.js` 的 `TERRAIN.elev`):山脈 = 沿稜線的高斯脊(每條山各有高度與寬度)、高原 = 橢圓台地、再加丘陵雜訊。
  量化成 0~5 階的梯田。貼圖用「斜俯視」畫法:高的那一階往南長出懸崖暗面、北緣一格亮邊、東側一格陰影,
  陸地比海高一階(海岸也有懸崖)—— 跟體素建築的「看得到正面」是同一個視角,所以融在一起。
  貼圖的高程用畫布描線(快),3D 位移用解析式(只算幾萬個頂點),兩者同一組參數
- **3D 位移**:近看的那一片曲面照高程往上推(一半取梯田階數、一半取平滑高程),四邊收斂到 0 接回整球;
  建築、部隊、地標都站在同一個高度(`W3D.elevAlt`)
- **回饋**(`sfx.js`):8-bit 音效全部用 WebAudio 即時合成(沒有音檔)、手機震動(`navigator.vibrate`)、右側有靜音鈕。
  出牌落地:撞擊縮放 + 震動 + 聲音 + 依牌加料;按鈕做成:像素火花迸發 + 嗶聲;被擋:訊息列抖 + 低音;
  下一季:整張地圖一格一格溶解(像素轉場)+ 號角;新牌解鎖:琶音;部隊抵達:塵土 + 聲音;大爆炸:閃屏
- **武器冷卻**:飛彈 4 → 2 季、空襲 3 → 1 季。平衡改成「越用越不划算」:4 季內同一種武器每用過一次下一發貴 40%;
  同一個對手 4 季內每被打過一次,這一發效果打 6 折。狂轟可以,但很貴、很醒目(關注度)、效果遞減、對手會記恨派兵

  火星火箭飛到之後也鎖在火星;點城市或拉近拉遠會自動回到地球

### 火箭追焦鏡頭(第十九輪)

- **鏡頭跟著火箭**:發射時鏡頭從發射城市旁邊、跟火箭一起往上爬(火箭在上、地球的弧線在下);
  火星計畫轉向之後鏡頭跑到火箭後上方一路跟到火星,抵達後鎖在火星。星鏈發射結束回到發射城市上空。
  追焦時地上的名牌先收起來;系統設定「減少動態」時不追焦

### 太空鈕分開、星球放大、不再自己轉、部隊抵達的攻擊動畫(第二十輪)

- **太空鈕**:原本一顆鈕循環(字寫的是「下一步」,按了看到的不是字上那一顆),改成「🌙 看月球」「🔴 看火星」兩顆,
  在太空時多一顆「🌍 回地球」
- **星球可以放大到跟地球一樣**:看月球 / 看火星時鏡頭站在那顆星正外側,預設距離 = 星球半徑 × 3(跟看地球同一個比例),
  拉近 / 拉遠鈕改成靠近 / 遠離那顆星;直式手機自動站遠一點。火星放大到月球的約 1.4 倍(火衛跟著往外)
- **鏡頭不再自己往左轉**:拿掉閒置自轉(以前放著 9 秒會自己轉起來)
- **部隊抵達的攻擊動畫**:目標城市有對手(大本營、駐軍、來襲的部隊)→ 坦克 / 航母一輪砲擊、火炮齊射、步兵槍火,
  最後一發大爆炸加畫面震動;沒有對手 → 進駐的光圈與星星。只是畫面,攻防照原本規則在下一季結算

### 月球 / 火星有自己的畫面(第二十一輪)

- **像地球一樣操作**:側邊「🌙 月球」「🔴 火星」打開那顆星自己的 3D 畫面 —— 拖曳轉動星球(放開有慣性)、
  滾輪 / 雙指縮放(從整顆到貼近地表)、點建築看是什麼;上面可以切換另一顆,「← 回地球」或 Esc 回地圖。
  建築黏在星球表面固定的經緯度、跟著星球轉(之後要在上面蓋東西)。火星有薄大氣與兩顆小衛星在繞。
  火星計畫的火箭抵達後會直接進火星畫面

### 部隊抵達一定有攻擊動畫(第二十二輪)

- 第一版只有「目標城市有對手」才開打、而且系統開了「減少動態」就整段不播 —— 現在一律播:
  有對手是「⚔ 進攻」(砲擊 + 大爆炸 + 震動),沒有對手是「⚔ 掃蕩 · 佔領」(一樣開火、收尾小一點)。
  開打前鏡頭先轉到目標城市;按「下一季」部隊在規則上正式到位時,也會在那座城市再打一次

### 火星航線、著陸、連點兩下飛到星球(第二十三輪)

- **回地球真的回地球**:火星計畫之後鏡頭一直鎖在火星(按回地球還是停在火星)。現在回地球會解除鎖定、
  鏡頭從太空拉回大本營上空
- **不再穿過地球**:火箭繞著地球外側飛(方向慢慢轉向火星、同時越飛越遠),鏡頭跟在後面,後半段轉頭看火星
- **著陸動畫**:到了直接進火星畫面 —— 登陸艇從上空一路減速降到登陸場(反推火焰閃爍)、落地揚起一圈沙塵、「🚀 著陸成功」
- **連點兩下飛過去**:地球畫面拉遠看得到月球 / 火星時,在它上面連點兩下 → 鏡頭飛過去、打開那顆星的畫面。
  星球畫面的角落有一顆小地球,連點兩下它(或按「← 回地球」)就飛回來

### 月球 / 火星跟地球同一套操作(第二十四輪)

- **不再切一次鏡頭**:星球畫面嵌在地圖那一格裡(頂欄、資源列、手牌都在),而且第一格畫面接的就是
  地球那邊最後一格的角度(同一個方向、同一個「幾倍半徑」的距離、同一個視角)—— 飛過去是連續的
- **操作跟地球一樣**:鏡頭繞著星球轉(拖曳沿經緯度移動、放開會滑一下)、滾輪 / 雙指 / 拉近拉遠改高度,
  貼近地表時鏡頭一樣會傾斜看地平線。星球本身不動,所以背景的地球、另一顆星、星星會跟著鏡頭換位置
  (位置照太空場景的真實相對位置,同一把尺)
- **跟地球一樣的比例尺**:星球半徑從 14 格加到 30 格(月球 26),建築縮小到跟地球上的城市差不多的比例;
  基地那一塊整過地(壓平),之後才有地方蓋
- 在星球上時側邊多一顆「🌍 地球」;要拖到城市的牌在星球上先擋下來(太空專用的牌之後加)

### 對手出局提示、偵察回報時機、分得清你和對手、現金搬家(第二十五輪)

- **對手出局**:被別的對手併購、或被你敵意收購到剩不到 2 億 → 跳一張出局卡(誰、哪一季、怎麼出局、誰接收了地盤),
  寫進新聞;對手頁與富豪榜列出「💀 已經出局」
- **偵察機**:起飛時只說「起飛了」,飛到繞完一圈才回報「偵察完成」、情報報告才出來
- **分得清是誰的**:部隊標籤前面多一塊色牌 —— 你的是藍色「你」,對手的是他的顏色 + 頭像 + 名字第一個字
  (同一國兩個對手、同一面國旗也分得開);城市名牌上你的標「你」,對手的標他的色牌與「大本營」
- **對手名字點得開**:勢力表、國家面板、規模比較裡的對手名字都可以點 → 開他的資料卡(身家、關係、大本營在哪),
  「📍 看大本營」直接飛過去
- **現金**:移居只改稅務居住地,現金放在哪一座城是另一件事 —— 移居面板寫清楚,並直接給「把現金搬過去」。
  現金可以放的城市從「私人銀行中心」放寬到「有銀行或證券交易所」(第一版東京、上海、法蘭克福都放不了錢)。
  城市名牌上的金額只算你自己在那裡的資產,對手的不算進去(有測試守著)
- **沒人的國家就是沒人的**:第一版只要對手在那個經濟圈有勢力,連一棟都沒有的國家(日本、韓國…)也塗成他的。
  現在國家要**真的有東西**才算誰的:你有資產或駐軍、對手的大本營或駐軍在這國;都沒有就是空白

### 國家顏色 = 經濟圈第一名(第二十六輪)

- 國家整片塗「那個經濟圈的勢力第一名」(跟面板上「X 的天下」同一個數字):中國是鄭天賜的,就算他的大本營在香港;
  你領先的城市(例如上海)另外塗你的顏色、蓋在國家顏色上面。沒有任何人在那一國建設或駐軍 → 不上色、寫「沒人的地方」。
  一國過半的城市是你的 → 整國是你的(不變)。顏色調深一點,不再淡到跟地形分不出來

### 月球 / 火星建地與太空競賽(第二十七輪)

- **固定建地**(像大富翁的格子):月球 6 塊、火星 10 塊,各有名字(`TY_PLOTS`),散在地表上,地形會自動整平。
  火星半徑放大到 36,塞得下 10 塊
- **前置條件**:月球要先「登月」(`tyMoonLand`,2 點);火星要把火星計畫走完(第 4 階段,殖民地自給自足)
- 建築:月球 氦-3 礦場／太空港(火星計畫與補給費打折)／通訊中繼站(星鏈收入 ×1.25);

- **每季補給費** = 造價 2%,付不出來那一塊整季停擺、沒有收入
- **算進身家**:太空建築以造價 9 成計入淨值 → 影響最終排名;結算畫面有「太空霸主」

- 點星球上的建地 → 開建地面板(蓋什麼、誰的、補給費、競賽進度)

## 搬家時真正動到的東西

抽出來之後跑測試,20 條裡有 5 條失敗。**全部都是環境差異,沒有一條是遊戲壞了**:

| 症狀 | 真正的原因 |
|---|---|
| 20 條全部卡在 `waitForFunction` 逾時 | harness 在等 `window.loadPF` —— 那是資產 App 的存檔函式,這裡沒有。改等 `tyStart` |
| 指揮台塌成 138px 高,上下兩列疊在一起 | 主 App 把每一頁包在 `.pg > #pgBody` 裡,**全螢幕的高度完全靠那兩層撐**。第一版直接把 `.tycon` 塞進 `#page` |
| `GLOBE_OK` / `countries` / `iso` / `FX` / `getRes` is not defined | 相依沒帶齊。一個一個補,測試會告訴你下一個是誰 |
| 佈景切換鈕看不到 | 有一條 `body[data-route="tycoon"] #topnav{display:none}` —— 指揮台是全螢幕的,主 App 的導覽列在這一頁本來就讓開。改成獨立的浮動鈕 |

### 兩條必須改寫的測試

**「模擬器不可以碰到真實的持倉與交易紀錄」** → 改成**「只准寫自己的那一格存檔」**。

這個 repo 裡根本沒有真實資產可以被弄髒 —— 那條風險是**結構上消失**的,
不是被測出來的。但規矩本身要留著,所以改成測同一件事的另一面:
玩完一整局之後,`localStorage` 裡除了 `TY_KEY` 和佈景設定,不可以多出任何一個 key。

**「切分頁不會一直生出新的 WebGL context」** → 原本測的是「切到 `#/holdings`
之後地球要回停車位」。這個遊戲只有一頁,沒有別的分頁可以切。

查了 `bindTycoon` 才發現原本那條**測錯了對象**:

```js
if(TY){ tyGlobeMount(); … } else tyParkGlobe();
```

地球回不回停車位,是「**這一局還在不在**」決定的,不是哪一個分頁、
也不是有沒有開面板(面板打開時地圖只是被 CSS 收起來,地球還掛在槽裡)。
所以改成測:放棄這一局、回到選劇本的畫面之後,地球要被收回去。

> 為什麼要在意:`renderPage()` 每次都 `innerHTML` 清空 `#page`。地球如果直接
> 畫在分頁裡,每重畫一次就是一個新的 WebGL context —— 瀏覽器同時只給十幾個,
> 切個幾次整顆地球就再也畫不出來,**而且不會報錯,只是變成空白**。

## 部署

Cloudflare Workers,從 Git 自動部署。`wrangler.toml` 是**唯一事實來源** ——
每次 `git push` 觸發部署,Cloudflare 會用那個檔案重建整份設定,
Dashboard 上手動加的東西會被清掉。要改設定就改那個檔案。

沒有 KV、沒有密鑰、沒有任何使用者資料。
